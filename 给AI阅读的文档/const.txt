================================================================
 KubeJS 全局/局部声明参考（避免重复声明错误）
 更新日期: 2026-06-23
================================================================

在 KubeJS 7 (Rhino) 中：
  - const 在顶层声明 → 全局可见，不可重复声明
  - var   在顶层声明 → 全局可见，可重复声明（但应避免）
  - function           → 全局可见（等同 var）

因此：只要看到某文件用 const 声明了某变量，其他文件就绝对不能再
用 const/var/let 声明同名变量，否则报 redeclaration error。

================================================================
 快速核查规则（写新代码前必看）
================================================================

在写新代码前，先检查以下声明是否存在（存在则不可重复声明）：

  1. $ByteTag              ← 已 const，不可重复声明
  2. $IntTag               ← 已 const，不可重复声明
  3. $CompoundTag          ← 已 const，不可重复声明

  4. 以下 const 常量名：
     PANE, PROF_TAG_LIST, ATTACH_SLOT_POS, SLOT_TRANSLATE_KEY,
     PROF_CONFIGS, PROFESSIONS, BACKPACK_SLOT_COUNT, BACKPACK_PAGE_SIZE,
     TAOV_RETURNED_BLOCKS_PER_REPAIR_PART, TEAM_REVIVE_CONFIG,
     SBW_VEHICLE_CONFIG, TEAM_ATTACK, TEAM_DEFENSE, TEAM_SPECTATOR,
     TEAM_NONE, JOIN_BATTLE_SCOREHOLDER, JOIN_BATTLE_OBJECTIVE,
     JOIN_BATTLE_TARGET, JOIN_BATTLE_FUNCTION, CLEAR_DELAY_TICKS,
     DYE_COLORS, LOCOMETAL_NORMAL, LOCOMETAL_ANTIBLAST, LOCOMETAL_ANTIPEN,
     CREATE_CASINGS,
     VEHICLE_STATE, VEHICLE_STATE_TRANSITIONS, VEHICLE_STATE_LIST

  5. 已注册的 item ID（不能再注册同名的）：
     kubejs:profession_selector
     kubejs:team_selector

  6. 其他 $ 开头的 Java 类引用（$ListTag, $FloatTag 等）：
     - 在其他文件中用 var 声明是安全的（不会报错）
     - 但最佳实践是在用到它的文件内用 var 自行声明，不依赖外部

  7. 所有用 function 声明的全局函数（见第七节）：
     - function 在 Rhino 中是全局可见的（等同 var）
     - 不可在同一作用域内用 const/var 声明同名函数（会冲突）
     - 但可以放心调用，无需重复声明

  8. global.taovReturnedAutocannon：
     - 通过 global 对象注册，不会和其他 const/var 冲突
     - 访问方式：global.taovReturnedAutocannon.xxx
